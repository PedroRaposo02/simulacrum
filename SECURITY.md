# Security

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through
GitHub: **Security → Report a vulnerability** on this repository. Include what you found, how to
reproduce it and what it affects (website, desktop app, update process, release workflow).

You'll get an answer as soon as possible, and a fix is released before the details are made
public.

## Scope

- The website and the desktop app, including its update process.
- The release workflow and anything that ends up in a release.

Wrong damage numbers aren't security issues; open a normal issue for those.

## Downloads

Only download the desktop app from this repository's
[Releases](https://github.com/PedroRaposo02/simulacrum/releases) page. Updates are signed and the
app refuses updates that aren't. Never run files or scripts posted in issues or comments.
